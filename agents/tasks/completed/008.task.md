# Task 008: React + shadcn/ui Frontend Dashboard (Axios Client, React Query & Zustand)

## Objective

Build a responsive local web interface using React, Tailwind CSS, shadcn/ui components, TanStack Query, Zustand, and Axios to configure episodes, monitor pipeline state with auto-revalidation, preview/regenerate audio chunks without prop drilling, and trigger native downloads.

## Implementation Details

1. **Network Layer (`/frontend/src/api/`):**
   - Create `apiClient.ts`: An Axios instance configured with `baseURL: import.meta.env.VITE_API_URL || '/api'`, standard headers, and a response interceptor for global error handling (triggering toasts via `sonner`).
   - Create `endpoints.ts`: Typed Axios wrappers for all backend routes:
     - `getProjects()`
     - `getDefaults()`
     - `getProject(id)`
     - `createProject(payload)`
     - `resumeProject(id)`
     - `regenerateChunk(projectId, chapterNumber, chunkId, payload)`
     - `downloadMediaUrl(projectId, artifact)`
2. **Server State Management (TanStack Query):**
   - Wrap application root with `QueryClientProvider`.
   - Custom Hooks in `/frontend/src/hooks/queries/`:
     - `useProjects()`: Fetches project list.
     - `useProjectDefaults()`: Fetches default profile parameters and system prompts.
     - `useProject(id)`: Queries `getProject(id)` with dynamic `refetchInterval`: polls every 1500ms while `status === 'IN_PROGRESS'` or `status === 'SYNTHESIZING_AUDIO'`, and stops polling when `COMPLETED` or `FAILED`.
   - Custom Mutations in `/frontend/src/hooks/mutations/`:
     - `useCreateProjectMutation()`: Invalidates `['projects']` on success.
     - `useResumeProjectMutation()`: Invalidates `['project', id]`.
     - `useRegenerateChunkMutation()`: Performs optimistic status updates and invalidates `['project', id]` on settlement.
3. **Client State Management (Zustand):**
   - Create `useAudioPlayerStore` in `/frontend/src/store/audioPlayer.store.ts`:
     - State: `activeChunkId: string | null`, `audioUrl: string | null`, `isPlaying: boolean`, `volume: number`.
     - Actions: `playChunk(chunkId, url)`, `pause()`, `setVolume(v)`.
     - Rationale: Eliminates prop drilling for audio controls across deep chapter/chunk trees.
   - Create `useUiStore` in `/frontend/src/store/ui.store.ts`:
     - State: active navigation tab, expanded accordion chapters, selected project ID.
4. **View 1: Episode Creator & Prompt Studio (`CreateProjectView.tsx`):**
   - Form state managed with controlled inputs populated by `useProjectDefaults()`.
   - Fields: Topic input, Architect/Writer Model selection, Architect `Reasoning Effort` Select (`none`, `low`, `medium`, `high`), Writer `Reasoning Effort` (default `none`), Voice blend formula input (`bm_george*0.65+bm_lewis*0.35`), Speed slider (`0.70`–`1.10`), Max chunk chars input (`200`).
   - Collapsible tabbed editors (`Textarea`) for customizing `architect.system.md` and `writer.system.md`.
5. **View 2: Live Pipeline Monitor & Inspector (`ProjectDetailView.tsx`):**
   - Driven by `useProject(id)`.
   - Overall progress bar (completed chunks / total chunks), current stage badge, and `Resume` button on error.
   - Accordion displaying all chapters with durations and cumulative timestamps.
   - Expanded chapter displays syntactic chunks: chunk text, pause badge (`pauseAfterMs`), inline audio play/pause toggle (connecting to `useAudioPlayerStore`), and an edit/regenerate dialog triggering `useRegenerateChunkMutation()`.
6. **View 3: Production Export & Downloads Hub (`DownloadsPanel.tsx`):**
   - Native download triggers for master artifacts:
     - `Download Master Audio (.FLAC)`
     - `Download Master Audio (.WAV)`
     - `Download YouTube Timestamps (.TXT)` + one-click clipboard copy box
     - `Download NLE Timeline Markers (.CSV)`
     - Per-chapter `.WAV` download buttons.
7. Configure Vite proxy in `/frontend/vite.config.ts` forwarding `/api` to `http://localhost:3000`.

## Verification Criteria

- `npm run build` in `/frontend` passes with zero TypeScript errors.
- TanStack Query auto-polls while the pipeline is synthesizing and pauses polling once completed.
- Audio preview playback functions seamlessly without causing full chapter-list re-renders.
- Calling chunk regeneration updates the UI state immediately via React Query cache invalidation.
- File download buttons successfully stream `.flac`, `.wav`, `.txt`, and `.csv` files to the local disk.
