# Task 007: NestJS REST API Controllers (Pipeline Control, Chunk Regeneration & Media Streaming)

## Objective
Expose REST endpoints for the React UI to create/monitor projects, customize prompts and reasoning modes, regenerate single chunks, and stream/download large audio files safely.

## Implementation Details
1. Enable CORS in `/backend/src/main.ts` and configure global Zod validation pipes.
2. Implement `ProjectsController` (`/api/projects`):
   - `GET /api/projects`: Returns summary list of all projects sorted by `createdAt` desc.
   - `GET /api/projects/defaults`: Returns the default `profileSchema` values and the contents of `/prompts/architect.system.md` and `/prompts/writer.system.md` to pre-fill the UI form.
   - `POST /api/projects`: Validates payload with `profileSchema`, initializes the project via `StateManagerService`, and enqueues the outline generation job.
   - `GET /api/projects/:id`: Returns the full `state.json` and `outline.json` for real-time UI polling.
   - `POST /api/projects/:id/resume`: Scans `state.json` for the current incomplete stage and re-enqueues pending chapters, chunks, or mastering tasks.
   - `POST /api/projects/:id/chapters/:chapterNumber/chunks/:chunkId/regenerate`: Accepts optional overrides (`text`, `ttsVoice`, `ttsSpeed`, `pauseAfterMs`), re-synthesizes only that specific chunk, re-runs `assembleChapter` for that chapter, and re-runs `masterProject`.
3. Implement `MediaController` (`/api/projects/:id/media`):
   - `GET /api/projects/:id/media/chunks/:chunkId`: Streams the chunk `.wav` file with `Accept-Ranges: bytes` support for the in-browser `<audio>` player.
   - `GET /api/projects/:id/media/chapters/:chapterNumber/download`: Streams `ch_XX_master.wav` using NestJS `StreamableFile` (`fs.createReadStream`) with header `Content-Disposition: attachment; filename="ch_XX.wav"`.
   - `GET /api/projects/:id/media/download/:artifact` (`wav` | `flac` | `timestamps` | `markers`): Streams `master_final.wav`, `master_final.flac`, `youtube_timestamps.txt`, or `timeline_markers.csv` directly from disk via `StreamableFile` without buffering into Node.js RAM.

## Verification Criteria
- Calling `GET /api/projects/defaults` returns valid default settings and system prompts.
- Calling `GET /api/projects/:id/media/download/flac` and `/timestamps` returns HTTP 200 with `Content-Disposition: attachment` and streams the file cleanly.
