# Task 001: Monorepo Scaffolding (`nest new`, React UI) & Docker Infrastructure

## Objective
Initialize the backend using the official NestJS CLI, scaffold the frontend using Vite + React + shadcn/ui, and configure a unified `docker-compose.yml` orchestrating `redis`, `kokoro-tts`, `polza-api`, and `backend`.

## Implementation Details
1. Create root asset and data directories: `/assets/voices`, `/assets/ambient`, `/projects`, `/prompts` (with `.gitkeep` files).
2. Initialize the backend strictly via NestJS CLI (if not already initialized):
   `npx @nestjs/cli new backend --package-manager npm --strict --skip-git`
3. Install required backend dependencies inside `/backend` (do NOT install `bull-board`, `nest-commander`, or `js-yaml`):
   `npm install @nestjs/config @nestjs/bullmq bullmq ioredis zod ai @ai-sdk/openai sentence-splitter number-to-words execa`
   `npm install -D @types/number-to-words`
4. Initialize the frontend inside `/frontend`:
   `npm create vite@latest frontend -- --template react-ts`
5. Install required frontend dependencies inside `/frontend`: `tailwind-css, axios, zustand, tanstack-query, lucide-react`
   Configure Tailwind CSS and install core **shadcn/ui** components (`button`, `card`, `input`, `textarea`, `select`, `progress`, `tabs`, `badge`, `scroll-area`, `slider`).
6. Create `/backend/Dockerfile` based on `node:22-alpine`. Crucially, install `ffmpeg` (which includes `ffprobe`) via system packages:
   `RUN apk add --no-cache ffmpeg`
7. Create `/polza-api/Dockerfile` based on `node:22-alpine` that installs dependencies (`npm ci`), copies `src/`, and runs the proxy server using the mounted `config.json`.
8. Create the root `docker-compose.yml` defining 4 services on a shared `bsap-network`:
   - `redis`: `redis:7-alpine`, port `6379:6379`, `redis-server --appendonly yes`, persistent volume `redis-data`, healthcheck via `redis-cli ping`.
   - `kokoro-tts`: `ghcr.io/remsky/kokoro-fastapi-gpu:latest`, port `8880:8880`, NVIDIA GPU reservation (`driver: nvidia`, `count: 1`, `capabilities: [gpu]`).
   - `polza-api`: build `./polza-api`, port `4000:4000`, volume `./polza-api/config.json:/app/config.json:ro`.
   - `backend`: build `./backend`, port `3000:3000`, `depends_on` (`redis`, `kokoro-tts`, `polza-api`), environment variables from `./backend/.env`, volumes mounting `./projects:/app/projects`, `./assets:/app/assets`, and `./prompts:/app/prompts`.
9. Implement a startup health-check job in `/backend/src/modules/queue/` that enqueues and processes a single test job on application bootstrap, logging `"BullMQ & Redis pipeline connection verified"`.
10. Create root `.gitignore`, root `.env.example`, and `/backend/.env.example`.

## Verification Criteria
- Running `npm run build` inside `/backend` succeeds with zero TypeScript errors.
- Running `npm run build` inside `/frontend` compiles the React bundle cleanly.
- Running `docker compose config` validates the multi-container setup without errors.
- Starting the backend with Redis running logs `"BullMQ & Redis pipeline connection verified"`.
