# Task 006: FFmpeg Audio Engine (Concat Demuxer Assembly, Ambient Loop & `lavfi` Mastering)

## Objective
Assemble chapter audio safely using the FFmpeg Concat Demuxer, construct a seamless slow-stretched ambient bed, apply the `lavfi` studio mastering chain, and generate YouTube timestamps and NLE timeline markers.

## Implementation Details
1. Implement `FfmpegService` in `/backend/src/modules/audio/` using `execa` to run `ffmpeg` and `ffprobe`.
2. **Step 1: Chapter Stitching (`assembleChapter`):**
   - For each chunk `.wav` in the chapter, apply a micro anti-click fade (`afade=t=in:st=0:d=0.015,afade=t=out:st=<duration-0.025>:d=0.025`) and normalize sample rate/channels (`24000 Hz`, `mono`, `pcm_s16le`).
   - Generate (and cache in `/projects/<id>/chunks/silence/`) exact silence `.wav` files (`silence_600.wav`, `silence_2000.wav`, etc.) matching `24000 Hz`, `mono`, `pcm_s16le` using `anullsrc`.
   - Write `/projects/<id>/chapters/ch_XX_concat.txt` listing interleaved chunk files and cached silence files (`file '../chunks/...'`).
   - Execute `ffmpeg -y -f concat -safe 0 -i ch_XX_concat.txt -c copy chapters/ch_XX_master.wav`.
   - Measure exact chapter duration via `ffprobe`, update `state.json`, and if all chapters are assembled, enqueue `master-project`.
3. **Step 2: Seamless Ambient Bed (`buildAmbientBed`):**
   - Read ambient tracks from `/assets/ambient/`.
   - Time-stretch each track (`atempo=0.65`) and crossfade them together (`acrossfade=d=15`) into a seamless loop file `/projects/<id>/output/ambient_cycle.wav`.
4. **Step 3: Final Studio Mastering (`masterProject`):**
   - Concatenate all `ch_XX_master.wav` files via Concat Demuxer into `output/voice_raw_full.wav`.
   - Run the master FFmpeg filtergraph combining `voice_raw_full.wav` and `-stream_loop -1 -i ambient_cycle.wav`:
     - **Voice Filterchain (`[0:a]`):**
       `highpass=f=75,equalizer=f=135:t=q:w=1.2:g=2.5,deesser=i=0.4:m=0.5:f=0.5:s=o,lowpass=f=6500,acompressor=threshold=-20dB:ratio=3:attack=20:release=250,loudnorm=I=-18:TP=-2.0:LRA=7,apad=pad_dur=15[voice]`
     - **Ambient Filterchain (`[1:a]`):**
       `volume=-32dB[ambient]`
     - **Mix & Fade Out:**
       `[voice][ambient]amix=inputs=2:duration=first:dropout_transition=0,afade=t=out:st=<total_duration+5>:d=10[out]`
   - Export both `output/master_final.wav` (PCM 16-bit, 44.1kHz) and `output/master_final.flac` (lossless compressed for fast downloads).
5. **Step 4: Metadata & Markers Export (`MetadataExporterService`):**
   - Compute cumulative timestamps from chapter durations.
   - Write `output/youtube_timestamps.txt` (`00:00:00 - Chapter 1 Title`).
   - Write `output/timeline_markers.csv` compatible with DaVinci Resolve / Premiere Pro (`#`, `Timecode In`, `Timecode Out`, `Name`, `Comment`, `Color`).
   - Mark project status as `'COMPLETED'` in `state.json`.

## Verification Criteria
- Automated test with 2 sample chapters (3 chunks each) and 2 short ambient `.wav` files produces `ch_01_master.wav`, `ch_02_master.wav`, `master_final.wav`, `master_final.flac`, `youtube_timestamps.txt`, and `timeline_markers.csv` with zero FFmpeg errors.
