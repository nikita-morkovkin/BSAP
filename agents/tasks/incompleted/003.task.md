# Task 003: Vercel AI SDK (`polza-api`) Integration & Two-Tier Script Generator

## Objective
Implement the LLM service using the Vercel AI SDK routed through `polza-api` with configurable reasoning effort, automatic retries, default English system prompts, and two-tier chapter generation.

## Implementation Details
1. Create default English system prompts in `/prompts/`:
   - `architect.system.md`: Instructs the Architect LLM to design a 15–20 chapter documentary outline for deep sleep, outputting strict JSON matching `outline.schema.ts` with rich scientific facts and sensory motifs.
   - `writer.system.md`: Instructs the Writer LLM to write slow, hypnotic, soothing narration without exclamation marks or Markdown, spelling out ALL numbers/dates/units as English words, and inserting `[PAUSE:2.0]` between paragraphs and `[PAUSE:4.0]` between thematic shifts.
2. Implement `PolzaLlmService` in `/backend/src/modules/llm/` using `ai` (`generateText`, `streamText`) and `@ai-sdk/openai` (`createOpenAI`):
   - Configure `createOpenAI({ baseURL: config.polzaApiUrl, apiKey: config.polzaApiKey })`.
   - Support passing `reasoningEffort` (`'none' | 'low' | 'medium' | 'high'`) via `providerOptions: { openai: { reasoningEffort } }`.
   - Configure `maxRetries: 5` and stream accumulation to prevent HTTP gateway timeouts on long chapter generations.
3. Implement `ScriptGeneratorService` and BullMQ processor `script.processor.ts`:
   - `generateOutline(projectId)`: Calls the Architect model (`architectReasoningEffort`), extracts and validates JSON against `outlineSchema.safeParse()`, saves `/projects/<id>/outline.json`, and updates `state.json`.
   - `generateChapterScript(projectId, chapterNumber)`: Checks idempotency via `StateManagerService`. Calls the Writer model (`writerReasoningEffort: 'none'`), passing the global outline, current chapter objectives, and the last 200 words of chapter `N-1` for seamless narrative continuity. Saves raw text to `chapters/ch_XX_raw.txt`.
   - State transition trigger: Once all chapters have `scriptStatus === 'COMPLETED'`, automatically enqueue the text normalization and chunking job for the project.

## Verification Criteria
- Unit/integration test verifies `PolzaLlmService` formats the `providerOptions.openai.reasoningEffort` payload and parses JSON outlines via `outlineSchema`.
- Running a 2-chapter test generation creates `outline.json`, `ch_01_raw.txt`, and `ch_02_raw.txt`, and skips Chapter 1 on a simulated restart.
