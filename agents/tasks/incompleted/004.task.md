# Task 004: Deterministic Text Sanitizer, Number Normalizer & Syntactic Chunker

## Objective
Clean raw LLM chapter scripts deterministically, convert any remaining digits/symbols into English words, extract `[PAUSE:X]` tags into metadata, and split text into syntactic chunks `<= 200` characters.

## Implementation Details
1. Implement `TextNormalizerService` in `/backend/src/modules/text/`:
   - Strip accidental Markdown formatting (`**`, `*`, `_`, `#`, backticks) and bracketed stage directions (except valid pause tags).
   - Extract universal pause tags `[PAUSE:X]` (e.g., `[PAUSE:2.5]`) and `[BREATH]`, converting them into structural break tokens with `pauseAfterMs = Math.round(parseFloat(X) * 1000)`.
   - Deterministically normalize numbers using Regex + `number-to-words`:
     - Decades: `1970s` -> `nineteen seventies`
     - Years: `1984` -> `nineteen eighty-four`, `2026` -> `twenty twenty-six`
     - Negative numbers & decimals: `-45.2` -> `minus forty-five point two`
     - Units & symbols: `%` -> ` percent`, `°C` -> ` degrees Celsius`, `°F` -> ` degrees Fahrenheit`, `km` -> ` kilometers`
     - Any remaining standalone integers -> words via `numberToWords.toWords()`.
2. Implement `ChunkerService` using `sentence-splitter`:
   - Split normalized text blocks (separated by pause tags) into individual sentences.
   - Greedily merge consecutive sentences into a single chunk as long as `combinedLength <= profile.maxChunkChars` (default `200`). If a single sentence exceeds `maxChunkChars`, split safely at the nearest comma, semicolon, or conjunction (`and`, `but`, `where`, `which`).
   - Attach the extracted `pauseAfterMs` (default `600ms` between normal chunks, or `2000ms–4000ms` where `[PAUSE:X]` was present) to the final chunk of each block.
   - Save `chapters/ch_XX_clean.json`, populate `state.json` with the chunk list, and enqueue sequential TTS jobs.

## Verification Criteria
- Unit test `text-chunker.spec.ts` feeding `"In the 1980s, **temperatures** reached -45.2°C (approx. 15%)! [PAUSE:3.5] Deep silence followed."` outputs chunks containing zero digits (`/\d/` test fails), zero Markdown symbols, `pauseAfterMs: 3500` on the target chunk, and every chunk length `<= 200` characters.
